# 报告补充数据

本目录保留报告中模型探索、输出投影、映射器真实RTL波形及镜头视场估计的离线结果。`source-bindings.json`记录原文件到发布副本的逐字节SHA256；旧记录中的本机绝对路径仅为原始来源标识。

- `kb-tangential/`：KB4-T2拟合候选、固定28训练／7留出评价、角点和数值复核；当前部署继续使用KB4四参数。
- `output-projections/`：固定当前KB4的离线输出投影比较；当前维持约125°透视输出。
- `mapper-waveform/`：xsim原始VCD及分析，23拍是映射器坐标接受延迟；不能替代整帧HDMI延迟或物理STA。
- `lens-fov/`：基于现行标定的视场估算，源画面水平约142°、垂直77°、对角167°；边角含外推，不是160°商品规格的精确验收。

上述材料均不改变正式位流、镜头参数或实板新帧率。完整原始采图及EDA工作目录不属于本补充目录；数值结果和输入身份在各JSON中保留。已部署版证据仍位于对应`delivery/`和`distortion/results/`冻结包。
