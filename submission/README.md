## 官方上传要求

依据用户提供的2026年FPGA创新设计赛道作品上传要求截图：

- 视频：MP4，AVC/H.264，建议3分钟内，300 MB以内；突出真实作品演示，不用PPT讲解代替；不出现学校、指导教师等与作品无关信息。
- 设计报告：使用官方模板，PDF，50 MB以内。
- 全部代码：RAR压缩包，200 MB以内。
- 承诺及使用授权书：官网下载、完成签字；不能以自动生成的文字代替签署。
- 项目GitHub链接：按企业选题指南开源。
- 照片：作品全景与开发板高清特写。
- 海报：根据企业要求上传。
- 截止：北京时间2026年11月4日18:00。

本目录提供的报告和海报不等于已经向竞赛平台提交。实物照片已补齐，报告和海报已重新导出并检查；当前仍须完成演示视频、签字文件及平台实际上传。

程序RAR仅选择上述两套主方案，其他1080p历史基线和诊断版本保留在仓库，不混入本次演示交付。报告PDF与海报仍按平台要求单独上传；包内副本仅供参考。

## 成绩与身份

最新HDMI摄像头方案在本地下载验证中达到1920×1080、30 FPS，新校正帧率相对15 FPS基线提升一倍。现场位流为`a266044d…`；其源码、原始时序和后续KEY1实现的区别见上方技术说明。

OV5640 720p15处理1280×720有效图像，29秒计数窗口内接受、处理和新显示各435帧，即15 FPS；HDMI配置为1920×1080p30扫描，720p画面居中显示。

HDMI 1080p15直接填充方案在599秒核心计数窗口内产生8,985个新处理／显示帧，约15 FPS；扫描17,970帧，其中重复扫描8,985帧。处理时长采样均值35.4515 ms。新帧率、扫描刷新与处理时长按各自口径记录。

两套正式工程分别提供冻结源码、独立位流、原生时序／资源报告与同版板测记录。具体身份及校验方式见上方两套方案入口；报告正文集中介绍系统设计与实测结果。
