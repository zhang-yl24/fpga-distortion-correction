## 官方上传要求

依据用户提供的2026年FPGA创新设计赛道作品上传要求截图：

- 视频：MP4，AVC/H.264，建议3分钟内，300 MB以内；突出真实作品演示，不用PPT讲解代替；不出现学校、指导教师等与作品无关信息。
- 设计报告：使用官方模板，PDF，50 MB以内。
- 全部代码：RAR压缩包，200 MB以内。
- 承诺及使用授权书：官网下载、完成签字；不能以自动生成的文字代替签署。
- 项目GitHub链接：按企业选题指南开源。
- 照片：作品全景与开发板高清特写。
- 海报：根据企业要求上传。
- 截止：北京时间2026年11月4日18:00。

本目录提供的报告和海报不等于已经向竞赛平台提交。当前仍须补实物照片、演示视频、签字文件；补图后重新导出并检查报告PDF。

程序RAR仅选择上述两套主方案，其他1080p历史基线和诊断版本保留在仓库，不混入本次演示交付。报告PDF与海报仍按平台要求单独上传；包内副本仅供参考。

## 成绩与身份

最新direct-fill位流SHA256为 `aa21991374fbeb4a6733741095f38e27336f1e47dd67b963feb243428a5b353b`。600秒采集包含599秒核心计数窗口、8,985个新处理／显示帧，约15 FPS；扫描约30 Hz，重复约15 Hz。处理耗时采样均值约35.45 ms，较旧tile8约44.33 ms下降约20%，帧率保持15 FPS。

原tile8回退位流SHA256为 `1236d82f113e1ddb1c5e24502ed1aa03e4758db0a7d6ff17bf9216f0fbd0e4f3`。两版参数和新帧率均有独立证据；不能按相同UART profile/build字段混用位流身份。

队友O/P约30 FPS是另一位流与电脑HDMI源下的记录；本机重编译O/P黑屏事件不作为成功成绩。fisheye60、E2、F等实验均保留各自验证边界，不作为本次15 FPS成绩的功能证明。
