# 演示视频拍摄方案（当前两版实板）

成片目标：2分40秒，横屏1920×1080，MP4 / AVC（H.264），300 MB以内。以用户提供的官方上传要求为依据，主体是实物和运行效果，学校名称、校徽、指导教师等身份信息不进入视频。含校徽的海报单独提交，不作为视频片头、背景或片尾。

当前上板为720p15，用户已确认校正画面正常。此前1080p15也已完成下载并由用户确认画面正常。本次下载成功及显示正常不构成一次新的帧率测量；视频性能字幕引用各自已有的同位流板测记录。

## 一、先按这个顺序拍，减少切换

1. 准备两个人：一人操作板卡和参照物，一人用手机固定机位拍摄。清理桌面和带身份信息的背景，理清线缆，准备平整硬质棋盘板、书架或门框等直线场景。
2. 保持当前720p15，接OV5640 CAM2。先试一次KEY1往返切换，确认模式，再拍全景、接口特写、连续原图/校正切换、边缘局部、动态物体；每项录两遍。
3. 同一套装置摆好后，另拍720p系统全景和开发板高清照片，不用从压缩视频截帧代替报告照片。
4. 720素材回放确认清晰、模式正确、切换完整后，再切到1080p15并接HDMI摄像头。由负责上板的人完成必要的连接调整、下载与画面确认。
5. 1080p15先试KEY1原图/校正往返切换，再拍同样一组镜头；补1080p系统全景与原图/校正照片。
6. 用已有板测和时序证据准备短字幕与一段约5秒的报告局部。最后剪辑、录旁白、完整回放检查并导出。

预计准备10分钟，720拍摄15分钟，切换及确认约5分钟，1080拍摄15分钟，剪辑旁白与导出检查35–50分钟；优先完成可提交成片，再考虑重拍美化。

结合本次实物照片，1080p继续使用房间柜门、门框和柜门上的棋盘作为场景，靠近画面两侧的直线便于观察变化。720p开拍前先把摄像头固定好，操作按键时手臂从镜头侧后方伸入，避免遮挡待观察区域；两种模式之间保持摄像头方向不变。

## 三、每套必须拍齐的素材

| 素材 | 单次建议录制时长 | 拍摄要点 |
| --- | --- | --- |
| 系统全景 | 10–15秒 | 摄像头、FPGA、显示器及接线都看得见，屏幕正在显示校正画面。 |
| 板卡与接口特写 | 8–10秒 | 看清输入、输出接口和板卡，不遮挡关键器件。 |
| 连续原图/校正切换 | 25–35秒 | 固定机位，原图静置8秒，按一次KEY1，画面稳定后校正保留10秒以上；保留手部操作与屏幕变化。 |
| 靠边直线局部 | 10–15秒 | 用平整棋盘、书架或门框，画面中心及边缘都保留有效参照。避免用弯曲纸张来判断几何校正。 |
| 动态画面 | 15–20秒 | 输入摄像头固定，缓慢移动书本、棋盘或手；保持原速，体现真实更新。 |

固定对照时，输入摄像头、参照物和拍摄手机都不要移动。原图与校正模式标注以实际显示为准，每次按键后等待画面稳定。各拍两条，手机镜头尽量正对显示器，避免把拍摄视角造成的透视变化混入比较。

按键需松开后再按，长按只切换一次。720版LED0、1080版LED6表示请求模式，实际画面稍后在完整帧交接时切换；拍摄时以屏幕中的稳定结果标注模式。两版KEY0都是复位键。1080正式版虽然具备KEY1切换逻辑，已有长短性能记录主要验证校正模式，因此先完成该正式位流的现场往返预演，再录连续切换镜头。

推荐先试拍10秒并回放：检查反光、滚条、摩尔纹、对焦和曝光。横屏1080p30，固定手机并锁定对焦/曝光；出现条纹时先调整屏幕亮度和手机防频闪/曝光设置，再试拍确认。只做正常剪辑、字幕、音量调整，保留真实播放速度和校正几何效果。

如后期使用左右并排对照，标注“同机位实拍剪辑对照”；不要让观众误以为板上同时输出分屏。主证据保留至少一段连续按键切换。海报中的PC参考校正图不用于冒充本次实板演示。


性能段落：

```text
720p15：29秒统计窗口，435个新显示帧
1080p15：600秒采集，599秒计数窗口，8985个新显示帧
两套实现：内部快慢角时序检查通过
```

这些数字来自保存的同版板测证据，画面中如展示数字，补一行“同位流已有板测记录”。无需重测或把拍摄时长写成统计窗口。15 FPS为新校正画面更新，30 Hz为输出扫描；1080p60输入规格也不等于60个新校正帧/秒。

中文字幕用微软雅黑，英文与数字用Arial。可用小面积紫色标题条或白底黑字字幕条，避免覆盖关键边缘和实际按键。单屏字幕最多三至四行；参数表、完整资源表和长公式留给报告。

正式片只展示两版已经具备的输入适配、几何校正、按键切换、持续更新和时序验证。镜头适配表述为“分别适配两类摄像头、按镜头标定配置”；旋转、Gamma、60 FPS、自动识别镜头、同时处理多路等不写成这两版已经完成的功能。

## 六、导出及提交检查

- 时长目标160秒，不超过3分钟；MP4容器，AVC/H.264编码，1920×1080、30 fps。
- 视频目标码率8 Mbps；旁白AAC 128 kbps时，160秒约163 MB，加少量封装开销仍留足300 MB余量。以最终文件实际大小为准。
- 旁白安静录制，背景音乐可省略；语音优先清晰。不要只改扩展名来代替实际编码格式转换。
- 从头回放最终导出文件，核对模式标签、两版身份、帧率含义、字幕可读性及声音；确认服装、桌面、屏幕、背景、片头片尾不出现校名、校徽、指导教师信息。
- 同时保存剪辑工程、原始素材和最终文件。建议提交文件名：`FPGA图像畸变校正系统_演示视频.mp4`。

本方案基于2026年11月4日当前两版，不沿用11月3日旧计划中的4.28 FPS鱼眼C版或未完成提速候选。
