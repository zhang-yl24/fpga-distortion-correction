# 作品海报

当前为 A3 竖版实物图科研展板，中文使用微软雅黑，英文和数字使用 Arial，字体已嵌入 PDF。白底、紫色标题与分隔线，包含1080p实板原图/校正屏摄、系统全景、720p板卡特写、系统流程图、真实 RTL 波形、实现结果表与处理耗时对比。报告字体仍为宋体/Times New Roman。

- [海报 PDF](作品海报_20261104.pdf)：用于单独上传。
- [海报 PNG](作品海报_20261104.png)：200 dpi 预览。
- [设计与核验记录](design-and-evidence.json)：记录图像来源、原始 VCD 身份、输出文件 SHA256 和字体/视觉检查。

版式参考[华盛顿大学科研海报模板](https://www.washington.edu/brand/templates/presentations/)的图文层级与分栏形式，布局重新绘制；紫色参考[清华大学标准色](https://vi.tsinghua.edu.cn/info/1150/1205.htm)。题头使用[清华大学官方VI校徽](https://vi.tsinghua.edu.cn/gk/xxbz/xh.htm)原图，白底紫色，保留原始颜色、字形和比例，校徽直径约27.9 mm，四边安全空间均超过直径的2/15。仅裁去原图多余白边，不重画或变形；[来源及SHA256](assets/tsinghua-emblem-source.json)随包保存。该校徽仅用于本海报。

图1为用户提供的1080p实板原图与校正模式屏摄，拍摄取景略有变化；图2为真实系统和板卡照片。四张照片仅做矩形裁剪和等比例缩小，保留校正画面黑边，逐图处理记录见`photo-assets.json`。图4来自实际 VCD 的KB4映射器单元测试，23拍不表示完整 HDMI 输入到输出延迟。两套工程分别适配不同摄像头，并非同时接入两路摄像头。

720p15 指 1280×720 有效采集与处理，HDMI 配置为 1080p30；1080p15 指 1920×1080 新校正画面约15 FPS，扫描为30 Hz。各自时序和资源对应选定版本，不混用历史候选成绩。

报告与海报已补入实物照片，8张照片的展示副本见[`../photos/`](../photos/)。视频按其上传要求不出现学校名称或校徽；本海报单独提交。程序RAR需从包含本次修改的固定提交重新导出，报告PDF与海报仍按平台栏目分别上传。
