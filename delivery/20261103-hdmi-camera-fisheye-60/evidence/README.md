# 验证证据索引

交付版本的源码身份、功能结果、物理时序与板测状态以包根目录的 `VALIDATION_STATUS.json` 为准。每项结果绑定当次源码；目录名称中的 `final` 只保留运行时的名称。

| 证据 | 内容 |
| --- | --- |
| `final-*-lat12` / `final-*-lat40` | 完整 1920×1080 像素、CRC、读写覆盖、处理周期；`physical-source-binding.json` 核验与对应原生构建的完整源码闭包一致 |
| `system-final-*` | 采集、CDC、DMA、帧槽、两路校正、显示与共享 DDR 争用；包含复位后的第二运行阶段 |
| `physical-*` | 原生 slow/fast 全类时序、DDR 约束审计、CA 局部复制等价性；路径详情按时钟域采样，汇总保留全部端点计数 |
| `cdc-fifo-*` | FIFO 同步器的综合属性、独立触发器和实际路由网表连线 |
| `cdc-user-audit` | 其它用户同步链、共享复位、无消费者裁剪及后续属性修复 |
| `cdc-gray-*` | 精确 Gray 路径 max-delay / skew 约束的绑定与原生测试 |
| `cache-*` / `writer-*` / `lane-*` | 对应模块的定向测试、背压、复位、协议错误和逐拍对照 |
| `video-control` | 输出完整帧、故障注入、调度/完成校验与独立代码复核 |
| `access-model` | 缓存容量、索引、分块与分工方案的访问次数实验 |
| `standalone-export` | 独立工程导出、路径迁移和哈希损坏拒绝测试 |

数字仿真使用指定 DDR 服务模型。硬件新显示帧率、长期稳定性及外部 IO 验收由实板记录证明。原生工具的大型原始报告以 SHA256 绑定，交付保留摘要与必要片段。
