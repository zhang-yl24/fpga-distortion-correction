# C 版鱼眼映射与访问吞吐分析

当前候选保持已上板 C 版的标定常量、1024 段 Q30 ROM、定点舍入、RGB565 和双线性插值。默认扫描顺序为 8×8 分块。32×8 仅作为可选对照参数，未替换默认值。

## 瓶颈定位

C 版 mapper 已为 23 级、每拍可接受一组坐标的流水线。其数据、ROM、乘法与标签在下游背压时一起冻结。基线引擎连续发射坐标；主要停顿来自邻域缓存未命中及结果写出。

按实际 C 版的 2,073,600 个整数映射坐标建立功能缓存模型，原 32 KiB、128 像素/缓存行、直接映射组织每帧需要 275,060 次填充，约 70.42 MB DDR 校正读量。这个数量与 C 版 UART 回执每帧约 27.4 万次填充相近。60 帧/秒对应校正读约 4.225 GB/s，尚未计入采集写入、结果写入和显示读取。

缓存访问模型逐查询模拟四邻域检查、慢路径依次取数与替换。它用于比较局部性，不模拟 DDR 争用、流水线逐拍行为或物理时序。

| 单缓存扫描顺序 | 完整帧填充次数 | 完整帧校正读量 |
| --- | ---: | ---: |
| 原逐行扫描 | 275,060 | 70.42 MB |
| **8×8 分块（默认）** | **49,465** | **12.66 MB** |
| 32×8 分块 | 49,465 | 12.66 MB |
| 32×16 分块（仅分析） | 32,633 | 8.35 MB |
| 32×32 分块（仅分析） | 24,171 | 6.19 MB |

更高分块需要更多结果重排存储。默认 8 行条带将每路双条带的逻辑存储控制在 61,440 字节。DRM 物理配置可能按深度/位宽取整，最终应读取 PDS 资源报告。

## 双路同帧划分

上路处理输出第 0–543 行，下路处理第 544–1079 行。两路 mapper 与采样器均保留完整 1920×1080 参数和源图像范围；输入纵坐标使用全局行号。标签与输出写地址在各路内从零开始，父模块组合两段光栅 CRC 后发布完整帧。

| 默认 8×8 | 上路 544 行 | 下路 536 行 |
| --- | ---: | ---: |
| 输出像素数 | 1,044,480 | 1,029,120 |
| 缓存填充次数 | 25,822 | 23,653 |
| 需要慢路径的查询 | 24,171 | 21,887 |
| DDR 校正读字节数 | 6,610,432 | 6,055,168 |

双路独立缓存合计 49,475 次填充，仅比单路完整帧分块访问多 10 次，60 帧/秒的校正读约为 0.760 GB/s。两路逻辑缓存总计 64 KiB，双条带总计 120 KiB，仍需计入输入/输出 FIFO 等存储。

125 MHz 单像素流水处理整帧的理想下限为 16.5888 ms，60 FPS 每帧预算仅余约 9,733 拍。双路空间划分为缓存填充和 DDR 争用提供更多处理余量。是否达到 16.67 ms，需要全尺寸 RTL 仿真和系统争用测量验证。

每路 mapper 包含 9 个 32×32 乘法流水，每个拆为 4 个小乘法，双线性插值另有 18 个乘法表达式。双路结构计数约 108 个乘法单元；常量优化与工具映射会改变 APM 实际用量，应以综合结果为准。

## 已实现的结果写出

两块完整条带交替接收分块像素与按光栅顺序读取，同步 BRAM 读流水可连续输出每拍一个像素。后级两个 256 像素 burst 缓冲允许继续打包与发送上一个 burst 并行。CRC 在恢复光栅顺序后计算。数据、标签、RAM 缓存块和已承诺 AW/W 的所有权一起管理。

## 复现

使用带 NumPy 的 Python，从发布 C 版 profile 与 ROM 生成原生整数映射：

```text
python tools/fisheye_integer_reference.py --profile <repo>/distortion/board/hdmi-camera-fisheye-profile.vh --radial <repo>/distortion/board/hdmi-camera-fisheye-radial-table.vh --output <work>/map.i32
node tools/analyze_cache_access.mjs <work>/map.i32 <work>/cache-access-results.json
```

完整原生映射字节 SHA256：`61354e91b499900343753f63687642d4672bba8ea717eefc8ecdd034f387a7a1`。每个像素包含小端 int32 的 Q15.8 x、y 坐标，按全图光栅排列。小尺寸系统测试必须使用参考函数的宽高缩放参数重新计算。

以上访问统计、RTL 单元/整机仿真、PDS 时序与最终板测分别记录。硬件验收继续独立统计新帧与重复帧。
