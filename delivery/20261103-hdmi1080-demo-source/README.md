# HDMI 1080p 演示源码交付与 60fps 后续目标

**今夜增量：** [离板候选与资源/时序表](offline-candidates/20261103-night/README.md) 已加入DMA5、纯校正PGSTAT02、Gamma、旋转+Gamma的完整身份与自有源码delta。DMA5当前离板setup为5条/−0.210ns；三个功能候选分别为38/−0.314ns、56/−0.379ns、194/−0.894ns，均未上板或全时序签核。D256与原生1080验证仍在推进，60新校正帧/秒、实板纯校正FPS和E2E未证明。[新增吞吐分支审查](NEW_THROUGHPUT_BRANCH_REVIEW.md) 单独记录最新12.54%隔离模型周期收益及其资源代价。

本目录交付 2026-11-02 晚已上板演示的 **电脑 HDMI 1920×1080、29.97Hz → DDR → 原图/畸变映射 → HDMI OUT** 源码。原图/映射约每 3 秒切换，按完整处理帧锁存模式。它是保留回退的诊断演示版，**不是 1080p60 完成版，也未完成时序或画质验收**。

用户已说明：今晚 HDMI IN 实际为电脑桌面；它只能证明链路出图，不能据此判断畸变校正效果。已购买的 1080p60 摄像头将作为后续演示来源。同学新上传 PR #21 已实屏验证 HDMI 摄像头1080p60源同步直通，详见[最新追加审查](LATEST_HDMI_CAMERA_1080P60_REVIEW.md)；具体型号、镜头K/D及主校正工程适配仍需核对。直通无DDR/校正，不能写成已处理60个新校正帧/秒。

## 当前结果及边界

| 项目 | 该冻结版本的结果 |
|---|---|
| 演示输入 | 电脑桌面 HDMI，1920×1080 progressive，29.97Hz |
| 固定模式 | Gamma OFF、旋转 0°、raw/映射慢切换 |
| 遥测窗口 | 60.066112 秒，1798 个完整帧扫描签名、1394 个不同输出 ID、404 次重复扫描 |
| 遥测传递速率 | 扫描签名约 29.9337 次/秒；不同 ID 约 23.2078 个/秒；均为主机采集窗口统计，含原图/映射混合模式 |
| 通信完整性 | 1799 个包校验通过，遥测 drop/abort/malformed 均 0 |
| 实际处理吞吐、内部耗时 | 当前 bit 未导出足够内部事件，未测得固定校正模式硬件 FPS/周期 |
| 端到端延迟 | 未测；仿真周期或 UART 到包时间不能替代 |
| 校正画质 | 桌面无匹配镜头 K/D、同源原图/校正像素对照与量化指标，尚未验收 |
| setup | slow 35 条，WNS −0.579ns；fast 0 条 |
| reset/IO | recovery slow/fast 245/226、removal 1/1；输入/输出 delay 缺项 55/111，尚未签核 |
| 输入准入 | `DIAGNOSTIC_BLANKING_REPORT_ONLY=1`；消隐偏差仅报告，非严格输入时序验收 |

资源来自同一个演示 ADF：FF 21936/133200（16.47%）、LUT 17133/66600（25.73%）、DRM 19.5/155（12.58%）、APM 69/240（28.75%）、IO 144/300（48%）。不将其他候选的更好 setup、资源或模拟帧率拼入这版成绩。

源码清单 130 项逐项绑定 SHA256；本交付含 50 项项目源码/头文件/约束、471935 字节，另 80 项厂商或派生依赖仅列哈希。对应的历史 bit SHA256 为 `2793ab0b6f1edb6429cb26b4cc927364cc1c512fe29f7c8b1dd473291374a819`，final ADF 为 `85fb2bcd0db1064c54b30f96982690d28dda59df1a1a6197eae504b2232287ef`。本目录不包含位流、ADF、授权文件、录屏或 EDA 缓存。

## 输入、原图与校正参数对照

这些是源码中固定的 **Penn frame240 1920×1080** 开发参数，不是电脑桌面的标定结果，也不是新购摄像头的标定值。源头文件 SHA256 为 `633cc52b3b5aff84c743fe7567487f871fc1e0d630f9bb121d9252db2fece607`；契约 `4be4883514d792116e4a0b8866356699314dd981e7ee312ddecf4261efd8d63b`。坐标中心从 0 开始；像素/焦距 Q8、逆焦距 Q30、Brown 系数 Q22。

| 参数 | 原图模式 | 校正模式源码定值 |
|---|---|---|
| 映射路径 | `sample_x=in_u`、`sample_y=in_v` | 逆旋转后执行 bounded Brown 映射 |
| 输出/源中心 cx, cy | 坐标直接采样 | 980.875, 523.9375 px |
| 源焦距 fx, fy | 不参与 identity 选择 | 1959.8359375, 1959.38671875 px |
| inv_fx, inv_fy（Q30 整数） | 不参与 identity 选择 | 547873, 547999 |
| k1, k2 | 不参与 identity 选择 | 0.2125298977, −0.4602301121 |
| k3, p1, p2 | 不参与 identity 选择 | 0, 0, 0 |
| 旋转 | identity 采样 | 0°，cos Q30=1073741824、sin=0 |
| Gamma | OFF | OFF |
| 输出像素链 | 相同 sampler、RGB565 结果 DDR、RGB888 扫描 | 同左 |

raw 不是电气直通，也不是只将畸变系数清零。当前交替模式使用不同输入帧，不能将相邻 raw/校正截图当作同一输入帧的严格对照。后续演示应把同一 source ID、真实镜头 K/D、输出 K/裁剪、旋转、Gamma、有效 mask、前后图像及直线残差/SFR 等指标绑定到同一次构建和采集。

## 复现与后续工作

先读 [构建准备说明](BUILD_REPRODUCTION.md) 与 [依赖说明](DEPENDENCIES.md)。`python -B tools/verify_package.py` 只核对交付源码；补齐精确依赖后，`tools/prepare_build.py` 可生成路径重定位的 Map 准备脚本。该脚本未自动运行 EDA，且不包含完整 PNR/最终时序签核或板端操作。

1080p60 的接口、DDR 和处理预算见 [60fps 与同学代码复用审查](PEER_REVIEW_AND_60FPS.md)。新目标要求分别证明输入 60Hz、输出 60Hz、每秒 60 个新校正帧；还要解决所有真实 setup、复位/IO 约束、资源与延迟，不能以刷新率代替吞吐或以桌面画面代替效果验收。

基础和提高任务仍需按正式题目逐项验收。本交付不宣布全项完成；动态旋转/Gamma、同源画质、固定模式 FPS、延迟与长期稳定性仍待完成相应验证。
