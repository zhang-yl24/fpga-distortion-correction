## 功能验证的准确范围

- DMA5保留既有AW/W、CRC、frame ID和周期，实际本地XSim成对测试有12046条trace，相关测试源码及原始结果摘要保留在`tests/dma-grant-equivalence`；不重跑EDA或硬件。
- PGSTAT02引用已有held CDC、原子统计快照/背压/复位和固定80/257向量验证，并叠加DMA等价修改；这个native rebase未重复运行整套长测试，新统计CDC物理签核仍未完成。当前UART双解析器共享原字节流的magic碰撞限制仍在，RX router修复未纳入；只支持另行校验的有界规范请求，不声称任意混流正确。
- Gamma引用实际bank级多光照/遮罩帧验证；组合旋转+Gamma引用作者3帧实际系统PASS。它们不证明新镜头光学效果、现场曲线选择、现场动态旋转或完整实时性能。位流已生成与真实演示已验收分开记录。
- 部分早期`INTEGRATION.json`保留“PNR待运行”等历史字段；完成状态采用绑定最终ADF、STA报告和bit身份的`RESULT_BRIEF.json`，不改写旧回执以制造全通过。

## 仍在进行及待测

D256 compact/prefetch与overlap writer仍在独立小系统、原生1080及物理容量/整机集成核验；当前状态快照不作60fps证据。completion CRC捕获实验已有控制/成对小系统和Map记录，最终物理结果未在本快照晋级。两者不混入上述四个native闭包。

尚未取得：固定纯校正实板接受/处理/唯一显示FPS、内部周期采样、端到端延迟、真实镜头同源画质、严格blanking和完整时序验收。输入/显示60Hz与每秒60个新校正帧分别计量。

固定profile测量工具v1现已按作者原始普通ZIP的198338B与SHA256核验后，交付[自有源码、测试与说明](../../measurement/pgstat02-v1/README.md)。38个作者文件保持原字节，6份RTL哈希绑定通过，交付端重跑34项内存测试通过；主线程另报25项合法/反例独立复核通过。这些只支持固定profile离线解析与一致性检查，不证明现场固件身份、实际125MHz、延迟分布或外部E2E。Library的Windows helper元数据阶段失败记录保留，未伪造元数据；本次直接使用作者明确提供的普通原件。旧v0不用于正式验收。
