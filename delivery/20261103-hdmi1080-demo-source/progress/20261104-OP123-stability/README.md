本次按已保存解码记录的offset，从原raw逐包独立核magic、固定长度、CRC及PGSIG尾标识，并核961628字节完整覆盖、无重叠/空隙；再对13个已解码统计记录复算计数差、核心窗口和帧率，对7504签名复算连续性/不同ID/重复。它不是从头独立实现的全部字段语义解析器，不能替代运行位流/采集epoch的现场身份论证。
