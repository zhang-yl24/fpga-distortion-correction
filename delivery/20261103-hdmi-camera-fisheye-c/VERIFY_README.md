# C 版离线核对

在干净克隆中使用 Python 3.10+ 标准库执行，无需串口、OpenCV 或 FPGA 工具。可从任意工作目录运行：

```powershell
python delivery/20261103-hdmi-camera-fisheye-c/verify_release.py
```

成功时输出 JSON 且退出码为 0，失败时输出错误并返回非零。检查包括发布清单中的 SHA256/字节数、原始与实际编译源码之间的变换闭包、发布位流与原上板回执的对应关系，以及标定原件、派生参数、部署投影和生成头文件的一致性。历史回执中的本机绝对路径仅作为来源文字，读取文件均使用当前克隆内的路径。

程序重新解码三段保存的 `wire.bin`，逐字段核对历史帧、CRC/身份/状态/模式/序号，并重算 FPGA 时钟帧率和主机到达时间交叉核对。全部测量窗口内空白帧增量为 0；启动累计的 7 次空白仍保留。程序同时逐个 1 秒采样累加 32 位计数器增量，恢复原图 29 秒窗口的完整 cache_hits（7,196,827,263），保留原回执首尾相减的历史结果不改写。该回绕修正不改变 FPS。

这是保存证据的离线复核，没有访问当前硬件、重新构建或重新签核时序，也不能确定复核当时开发板是否仍运行该映像。重新编译见 [源码与重建说明](SOURCE_README.md)；标定和预览图的范围见 [标定说明](calibration/README.md)。
