# 720p 离线开发证据（2026-11-01）

本包封存独立 `camera720_transport_top` 的开发进展，供提交审阅和后续接续。有效输入/处理尺寸为 1280×720，仍居中显示在 1920×1080p30 扫描中。板级候选使用单位映射；本包不包含 720p 镜头标定、位流或下载记录，不能当作可上板发布包。此前 VGA 实际镜头矫正的验收结论不转移到此候选。

## 已完成

- 传感器：9 个数字场景，包含真实初始化 I²C 状态机、42/47.25 MHz PCLK 的完整帧准入、停钟和坏行拒绝。
- 采集：4 个完整 720p 好帧、3,686,400 个像素独立核对；另含坏帧、DDR 阻塞溢出、排空恢复及缓存复用。
- 板层控制：8 个启动和 7 个运行故障场景；传感器/处理/IP 使用明确状态 stub，该测试不代替像素或电气验证。
- 处理输出：3 帧非线性合成映射，共 2,764,800 个坐标及实际扫描像素匹配；覆盖结果缓存复用、DDR 背压和处理/显示并发。
- 完整 system：真实 camera_vga_video_system 全链路共同执行，2 帧 1,843,200 个实际 HDMI 像素独立核对，CRC DF5734A7 / 73964307，零下溢/CRC 错误，最终排空；两帧不声称缓存复用。
- 原生综合/布局布线完成；新 VS 保持时间修路后，fresh STA 的 slow/fast hold 为 +0.061/+0.020 ns，setup 为 +0.148/+3.143 ns，均零失败。DDR recovery 仍有 245/229 个失败；时序整体未通过。
- 本次提交前统一 CPU 复核通过 196 项测试及 50 个子测试，原始 JUnit 记录在 reviews；这些测试不访问 EDA 或硬件。
- 精确 DDR 复位范围证明与原生端点查询完成；尚未应用约束。原始 ADF 的 CDC 结构枚举已完成，但最终派生候选的 CDC 原生时序核验尚未完成。

`hold-route-a/result.json` 原始失败回执保持不变：PDS 保存时发生同父相邻 CDBENTRY 重排及空 FILEMAP 占位删除，严格原始比较失败。后续 derived 检查限定核验这些非功能差异并重新绑定实际测量；`hold-export-a` 的 fresh STA/export 成功。不能将原失败回执改写成通过，亦不能据此豁免任意功能、放置或约束变化。

## 文件与验证范围

`manifest.json` 记录原件路径、原始字节 SHA256、压缩后 SHA256、仓库源码哈希及本地大型引用。小文件原字节保存；大报告以确定性 gzip（mtime=0）保存，解压后必须匹配原件 SHA。完全相同的原件共享一个存储文件，各源路径仍独立列出。历史失败/中止记录另列，未被用作通过证据。

大尺寸 ADF、功能网表、route dump 和像素/vector dump 只列在 LocalReferences，未随仓库分发；外部 PDS/Vivado/IP 工具也只按现有回执及哈希引用。原回执中的 Windows 绝对路径保留原样。本包可以审查已执行报告和源码绑定，不能脱离原本地输入重新完成物理授权，也不声称从任意电脑直接复现全部原生 EDA。SourceSHA256 与 InputSHA256 的完整原始映射仍保留在对应报告中。

以上仿真使用合成传感器和 DDR 模型，不证明实物电气、720p 实测帧率或光学清晰度。尚待应用并独立审计精确复位约束、最终双角时序及 CDC/引脚核验，再生成位流并通知用户上板；实图和该模式的镜头矫正验证后，才进入 720p 帧率优化。
