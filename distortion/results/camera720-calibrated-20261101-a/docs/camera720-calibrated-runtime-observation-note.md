# Runtime observation without changing the calibrated RTL

The current top has no UART RX/TX port, serial telemetry engine or inserted JTAG debug core. Its external status is the eight LEDs: bit 7 is sticky board/system failure; bits 6 and 5 are synchronized processed/captured frame counter bit 4; bits 4/3/2/1 indicate HDMI configuration, camera readiness, video PLL lock and DDR readiness; bit 0 is the reference-clock heartbeat. Evidence is the actual prepared top `camera720-calibrated/build-a/source/board/camera720_calibrated_top.v`, ports at lines 10–17, counter/status synchronization at 92–105, and LED assignment at 175–176. The native export contains no UART, DVIO or JTAG debug-core instance.

The existing owned JTAG programming path already records exact bitstream identity, successful program completion and post-program DONE. `program_native_raw.py:100` constructs the documented scan/property commands; its DONE checks explicitly limit the conclusion to configuration. The installed Fabric Configuration manual, PDF pages 88–89 (printed pages 87–88), documents `cfg_read_device_property -mode 0` for device ID, mode 2 for UserCode, and mode 3 for configuration status. These do not read application counters or LED values. A later bounded read of status could establish that DONE is still set at that sample, but cannot establish ongoing camera capture, successful correction, presentation FPS or optical correctness.

No supported nonintrusive external-pin SAMPLE/PRELOAD command was found in the installed Configuration command manual. “Boundary Scan” in its UI refers to selecting/scanning the JTAG device chain; that name alone is not evidence of access to live LED pins. The Debugger manual describes wave capture using an inserted debug core, which this candidate does not contain. Configuration memory readback is not an application status protocol and has mode-dependent device effects, so it is not proposed as a substitute.

The minimal current plan is to retain exact SRAM program/DONE evidence and leave real pipeline/optical observations pending until the user returns. No serial session, JTAG access, PDS process or RTL change was performed in this investigation. The source/document inventory is `camera720-calibrated/runtime-observation-document-index.json` with exact local manual hashes.
