## 包内内容与限制

`source/`保留本候选generated top/header/manifest；`evidence/geometry/`保留参数来源、配对与有限覆盖；`evidence/system/`保留真实仿真CRC和日志；`evidence/final/`及相关原生小回执保留复位、CDC/IO、位流与下载依据；`regression/`保留局部CI验证。原始metadata比较失败回执和后续精确重新审计均保留。

不复制房间原始图片、像素mem、ADF、完整网表、巨大STA报告、厂商可执行文件或文档。`referenced-local.json`记录被原证据引用但未打包的原位置/预期SHA；没有为这些省略文件重新执行全物理审计。冻结JSON中的绝对路径保持原字节，迁移后不能直接当作可执行闭包。`source-test-index.json`列出工具/源码/测试引用。

`manifest.json`逐个绑定所有实际复制及本包生成的文件；包内校验仅证明拷贝完整性，不新增硬件或光学验收。失败/历史记录仍保持原状态，以`status.json`及最终实际回执区分。
