## 包内内容

`bit/`、`program/` 保留生成/校验/下载的原始字节；`uart/` 保留 wire、包、窗口、主机读取记录和会话；`evidence/` 保留完整 CDC 证明、复位验效、最终查询回执、仿真与有限诊断说明；`source/` 为这次编译输入的 top、镜头参数、UART/延时模块与相机模式/约束快照。

`evidence/build-c/native-route-optimize.ror` 是本次原始布局的资源报告，不能用其中修复前的时序结果覆盖最终十表结论。完整原生 STA、ADF、网表与大量本机依赖未打包；省略项的原路径、大小与 SHA 见 `omitted-local-evidence.json`。包内回执保留机器上的绝对路径，不代表克隆后可直接重跑完整物理审计或构建。未复制相机照片、像素数据、厂商许可、可执行文件或厂商 IP 源码。

`copied-originals.json` 记录拷贝来源；`manifest.json` 绑定所有文件（不包括 manifest 自身）。这些是完整性信息，不是新的硬件测试。

## 离线复核

```text
python -B distortion/results/camera720-stats-live-20261102-a/verify_bundle.py
```
