旧同K输出映射失败，失败报告保留。新输出K=diag(240,240,1)、中心(319.5,239.5)在0°旋转下全307200坐标通过：最大误差0.056593px、溢出0、折叠0、双线性邻域100%在界内。它收窄视野；不是自动证明其他输出角度或上板通过。需要新radius guard11610104，不能沿用旧8388608。
