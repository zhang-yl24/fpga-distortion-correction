## 摄像头与内存接口约定

用户已确认断电后将摄像头移到 J2。2026-10-04 的 BASE-V1.4 实物近照显示 J20 跳线帽
位于 3V3 一侧，ADJ 一侧空置；BANK_L6/L7 按固定 3.3V 选择供电。这是跳线位置确认，
尚无万用表实测值。J24 用于选择 ADJ 支路电压，J20 选择固定 3.3V 时不使用该支路。
传感器硅片 ID 已由真实 COM5 日志确认为 5640；第二路初始化、关键寄存器回读和采集已验证。第一路输出使能故障尚未电气隔离。

数据路径：摄像头初始化 → DVP → 异步 FIFO → DDR 帧缓存 → 逆映射坐标计算 →
四邻域读取/缓存 → 双线性插值 → HDMI；上位机在帧边界更新参数和旋转角度。
DDR 写入帧与显示读取帧必须隔离；缓冲区切换只在帧边界进行。
像素坐标暂定有符号整数 + 8 位小数，负数按 floor 分解，不能向零截断。
越界的每个邻域样本各自填零；不要因为一个邻居越界就抹黑整个输出像素。
`black` 仅用于明确应全黑的像素；一般边界应送入已经逐邻域置零的四个 RGB 样本。
DVP 不能暂停，FIFO 溢出必须计数并丢弃/重同步整帧，不能悄悄忽略后仍报告成功。
逆映射四邻域 DDR 读取是关键瓶颈，先正确实现，再用行缓存/块缓存和突发访问减少等待。
没有 HDMI 线可以完成前端状态检查和核心开发；最终视频展示仍需 HDMI OUT 接显示器或采集卡。
板上的 USB-C 是 CP2102 USB-UART 接口，不支持 USB-C 视频输出。EHOMEWEI Q5 官方资料
列有 Mini HDMI 输入，可用标准 HDMI 到 Mini HDMI 线连接 HDMI OUT，并给显示器单独供电。
购买版本需确认接受 1920×1080@60Hz 和 1280×720@60Hz 的 HDMI 输入；当前尚未实机验证。
