# Guarded 单路原始采集验收任务

本轮目标是把已有数字租约接入真正板级版本：默认零采集，有效授权后有限采集，温度/状态陈旧时停止新增事务。照片很暗和没有棋盘格不阻止这些数字链路检查，但这些检查不构成新镜头画质、同步双目或长期热稳定性验收。

所有新候选保持独立命名，不改旧97项raw源和稳定基线；日志、测试及PDS输出只写已批准的`build/offline-20261024`。每次实板短测均须记录源码/位流/引脚/最终时序，保存全部收到的字节和发送命令，结束后重新下载heartbeat并确认新的DONE。不能把串口关闭当作板上待机。

| 编号 | 验收任务 | 通过条件 | 证据边界 |
| --- | --- | --- | --- |
| G1 | 启动后不授权 | 预热后仍只有新鲜PGSTAT02；admitted/completed=0，无PGFRAME | 需要实际经过温度、相机和DDR就绪；只看启动瞬间不足以证明默认零采集 |
| G2 | OPEN及只读QUERY | session和序号匹配、接受计数推进；零授权仍零帧 | 查询不能续租，不能把命令已发出当作板上接受 |
| G3 | 两帧预算、短租约、期间QUERY | 首帧开始后租约到期，首帧完整导出，第二帧不准入；状态显示LEASE_EXPIRED、admitted/completed=1 | 串口一帧约6.7秒，ACK可在完整raw包边界延后；查询不重置租约 |
| G4 | 重复完全相同GRANT | duplicate计数推进，授权和预算不增加；一帧预算只产生一个完整帧 | 重复包必须在同会话内核对，不能用文件名或帧号猜去重成功 |
| G5 | 首帧发送中STOP | 已开始的PGFRAME完整、CRC通过；之后零新增；停止原因OPERATOR_STOP | STOP生效前已被接受的事务允许排空，不中途复位DDR/UART |
| G6 | 授权后主机不再发命令 | 保持串口接收，有限租约/预算自行结束；新鲜状态的计数/原因符合预期 | 本轮未拔USB/关闭COM/杀进程；若另测断开，不认证遗漏期间的像素传输 |
| G7 | 无效参数/旧版本/旧序号 | 拒绝或RX错误计数增加，零新增授权/零额外帧 | 仅使用预定负例，不提供任意寄存器写入或无限重试入口 |
| G8 | 温度无效、过温、27MHz失效/快照陈旧 | 数字联合仿真中均失效关闭；在途事务完整排空 | 实板只观测真实有效温度，不故意过热；物理温度触发路径仍单独记为未诱发验收 |
| G9 | 所有退出路径 | 正常、超时、解析失败、编程失败后有独立heartbeat恢复回执及新scan DONE=1 | 主机进程被杀、供电或JTAG断开后恢复不由`finally`保证 |

先通过V2命令、反馈确认、温度CDC、包级TX所有权及小DVP/DDR/UART联合仿真，再通过独立PDS最后时序/全部129个预期active pins和源码闭包，最后开展有限实板测试。源码或候选改变后，对应实板证据不能自动继承。

CAM1独立输入是后续B1任务：原板参考14路与共享DDR/UART资源已离线审阅为无pad冲突，见`cam1-independent-input-pin-review-20261025.json`。须在CAM2 guarded候选稳定后单独派生、构建、下载和核对，不因两眼同型号而省略。两个独立单眼结果不证明同时采集、曝光同步或深度精度。

本轮实际状态：G1–G7均完成有限实板测试，完整记录见[持续开发成果](持续开发成果-20261025.md)。G8完成数字仿真，未故意诱发物理过温；G9有正常退出和CAM1初始化失败超时后的heartbeat实录，其余故障及杀进程后恢复不能继承。CAM1独立构建已完成，但真实初始化在3018写后读NACK，B1未通过。核心时钟停顿会暂停核心域租约/新鲜度计时，不能把它当独立墙钟看门狗。
