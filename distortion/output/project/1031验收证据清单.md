## 离线入口

`tools/assess_1080_evidence.py MANIFEST.json --output 新报告.json`只读记录；输出父目录须存在且文件不能覆盖。缺证据记`UNMEASURED`，字段类型、hash、回退、缺样、fault或模式失配会拒绝。物理throughput/stability/external_latency须用`{"record":{"path":"...","sha256":"..."}}`引用原始JSON记录；不能把inline自述或仿真数据当物理记录。

manifest最小结构如下；`null`代表待采/待声明，不能原样运行。所有窗口、温度、延迟和画质阈值必须由操作者预先明确并保留；不是本工具或官方认可的默认合格线。

```json
{
  "schema": 1,
  "evidence_kind": "physical_observation",
  "run_id": null,
  "identity": {
    "camera_id": null, "lens_id": null, "profile_id": null,
    "capture_mode_id": null, "image_size": [1920, 1080],
    "pixel_format": "RGB565_LE"
  },
  "requirements": {
    "threshold_origin": "operator_engineering",
    "target_new_frame_fps": null,
    "minimum_fps_window_seconds": null,
    "maximum_sample_gap_seconds": null,
    "minimum_stability_window_seconds": null,
    "maximum_temperature_c": null,
    "maximum_external_latency_ms": null,
    "minimum_latency_events": null,
    "minimum_temperature_samples": null,
    "maximum_line_deviation_px": null,
    "minimum_detail_score": null,
    "detail_score_unit": null
  },
  "native_input": null,
  "calibration": null,
  "quality": null,
  "throughput": null,
  "external_latency": null,
  "stability": null
}
```

- `native_input`：相同identity，raw/image/metadata三项`path+sha256`。metadata须声明真实物理来源、`hardware_accessed=true`、`geometry_applied=false`、原生角色/尺寸/格式/身份和hash-bound raw contract；本工具不重做raw→PNG逐像素比对，仍需已有独立采集审计。
- `calibration`：profile与dataset_manifest的`path+sha256`；复用现有档案与原图/metadata，不生成新K/D。开发档案、旧模式和边缘缺口均不能PASS。
- `quality`：相同identity、original/corrected/capture_metadata/measurement_record四项引用，chart_id/lighting_id/exposure_id一致。measurement记录两图SHA、直线/细节协议、reviewer、单位和实测值；工具只核记录与显式阈值，不计算SFR/MTF、不授予专业光学合格。
- `throughput`记录：identity、输出clock_id、source_clock_id、窗口start/end_ns，逐显示样本`timestamp_ns/display_id/frame_id/source_timestamp_ns/is_repeat/native_pixel_sha256`。窗口必须由样本覆盖，ID/时戳有序、不漏样；重复显示保留相同源ID/源时戳/hash。新帧率按整个窗口的新帧transition计算，重复刷新单列。新ID却重复像素内容记未测，需变化刺激辨别静止与冻结。
- `external_latency`记录：identity、`method=external_same_source_event`、`scope=source_event_to_output_observation`、external_observer与clock_id；每个独立event_id含input_event_ns/output_event_ns。仅给同clock名并不能证明外部端到端事件，仍需人工审核原始外部观测。
- `stability`记录：identity、clock_id、窗口、temperature_method（sensor_adc_approximate或external_thermometer），每个timestamp_ns含captured/processed/display_frames、ddr_errors/frame_errors/fault_count/fault_flags、temperature_valid/alarm/c。累计计数回退或任何错误不能PASS；ADC近似温度不等于校准温度计。

工具的`PASS_RECORD_CHECKS`只表示所供记录通过文件/hash/身份/算术检查，不认证人类声明或外部仪器、不验STA/bit、不代替评审；`real_acceptance_status`始终`UNMEASURED`。既有四项`HardwareReleaseAllowed/NewLensCorrectionVerified/CalibrationAccepted/PreBitGateExecutionProven`及额外`RealHardwareAcceptancePassed`始终false。合成单测必须`evidence_kind=synthetic_tool_test`，即使数值检查PASS，真实证据仍全为未测。显示reader.done只证明DDR→FIFO读完；既有显示valid为sticky，成功后再故障的撤销语义尚缺证据，不能单凭toggle释放前台银行。
